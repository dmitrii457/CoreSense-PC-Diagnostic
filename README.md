# CoreSense — интеллектуальная система диагностики ПК

![Python checks](https://github.com/dmitrii457/CoreSense-PC-Diagnostic/actions/workflows/tests.yml/badge.svg)

Настольное приложение Python с локальным помощником. Обновлённый интерфейс включает активную навигацию, примеры запросов, анимацию анализа и постепенное появление ответа. Расчёт выполняется в фоновом потоке.

[Соответствие неделям 4–15](docs/SYLLABUS.md) · [Сценарий защиты](docs/DEFENSE.md) · [Презентация](docs/CoreSense-Defense.pptx)

## Оформление и движение

В разделе «Режим защиты» можно показать распознанные факты, цепочку правил и план на готовых примерах.

Для запуска переносимой версии Windows распакуйте архив полностью и откройте `CoreSense.exe`. Папка `_internal` должна лежать рядом с ним. История переносимой версии сохраняется в `user_data` рядом с программой.

Для повторной сборки установите зависимости проекта и PyInstaller в `.venv`, затем запустите `build-windows.ps1` в PowerShell.

Единая графитовая тема с фиолетовыми акцентами, светлый вариант и общий стиль элементов. Все разделы используют плавное появление страницы. Кнопки меняют цвет при наведении и нажатии, карточки подсвечивают границы, поля показывают фокус. Главный экран включает анимированную орбиту и счётчики знаний. Ответы, выбор компонента и прогресс пошаговых проверок также анимируются.

Анимации используют один механизм отмены, учитывают быстрые переходы и отключаются в настройках. Обработку запросов это не задерживает.

Проверка расположения элементов и движения без захвата экрана:

```powershell
.\.venv\Scripts\python.exe tests/visual_smoke.py
```

## Диалоговая диагностика

- Уточняющие вопросы с ответами «Да», «Нет», «Не знаю», которые влияют на правила.
- Пошаговые проверки с отметками «Не помогло», «Помогло», «Пропустить».
- Локальная история с поиском и продолжением диагностики после перезапуска.
- Интерактивная схема компонентов с фреймами и связями.
- PDF-отчёты с поддержкой русского текста.
- Светлая, тёмная и системная темы, отключение анимаций.

[Как пользоваться новыми функциями](docs/FEATURES.md). История и настройки хранятся в `user_data/` и исключены из Git.

## Описание проекта

CoreSense — учебная экспертная система на Python для предварительной диагностики неисправностей персонального компьютера.

Система анализирует симптомы, применяет логические правила и использует обученные модели машинного обучения для определения возможной категории неисправности.

## Возможности

- Диагностика неисправностей ПК.
- База знаний в формате JSON.
- Логический вывод с AND, OR, NOT.
- Продукционная система с прямым выводом.
- Фреймовая модель с наследованием свойств.
- Семантическая сеть компонентов компьютера.
- Классификация неисправностей методом Random Forest.
- Простая нейронная сеть MLPClassifier.
- ИИ-помощник с анализом текстовых запросов.
- Графический интерфейс CustomTkinter.

## Технологии

Python, CustomTkinter, scikit-learn, pandas, NetworkX, Matplotlib, JSON.

## Установка

Создайте виртуальное окружение:

```powershell
py -3.14 -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если обученные модели отсутствуют, сначала создайте датасет и обучите модели:

```powershell
.\.venv\Scripts\python.exe -m modules.create_dataset
.\.venv\Scripts\python.exe -m modules.classifier
.\.venv\Scripts\python.exe -m modules.neural_network
```

## Запуск

```powershell
.\.venv\Scripts\python.exe app.py
```

## Принцип работы

1. Пользователь описывает проблему.
2. Система определяет известные симптомы.
3. Классификатор и нейросеть формируют прогнозы.
4. Экспертная система применяет логические правила.
5. Пользователь получает предварительный результат и рекомендации.

Неуказанные симптомы остаются неизвестными в механизме правил. Признаки для моделей бинарные, поэтому отсутствие упоминания кодируется нулём только на входе классификаторов. Их прогнозы отображаются отдельно от доказательств правил. Фреймы и семантическая сеть дополняют ответ сведениями о компонентах.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Демонстрационный запрос: «Компьютер не включается, индикатор питания не горит». В объяснении должны появиться R1 и R5.

| Метод | Accuracy | Macro F1 |
| --- | ---: | ---: |
| Random Forest, 100 деревьев | 76,54% | 0,57 |
| MLP, слои (32, 16) | 87,24% | 0,76 |

357 строк для обучения, 243 для теста. GroupShuffleSplit по вектору симптомов исключает одинаковые векторы между частями данных. Неравномерное распределение классов влияет на оценку. Отчёты с матрицами ошибок находятся в [reports/](reports/). Датасет и модели воспроизводятся командами обучения выше, seed=42.

## Структура

- `app.py`, `modern_ui.py`, `extra_pages.py`: графический интерфейс.
- `knowledge/`: факты, правила, фреймы и сеть.
- `modules/`: вывод, помощник, обучение и оценка.
- `data/`, `models/`, `reports/`: данные, обученные модели и результаты.
- `tests/`, `.github/workflows/`: проверки и GitHub Actions.

При отсутствии моделей приложение запускается с правилами. Для сравнения ML-прогнозов выполните обучение. Устанавливать зависимости лучше из этого requirements.txt: pickle-модели зависят от версии scikit-learn. Загружайте модели только из доверенного источника.

## Ограничения

Модели обучены на синтетическом учебном датасете. Их точность на тестовой выборке не подтверждает качество диагностики реальных неисправностей.
