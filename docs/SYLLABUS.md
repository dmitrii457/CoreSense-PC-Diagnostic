## Границы реализации

Помощник использует словарь фраз, а не большую языковую модель. Он распознаёт распространённые формулировки и простые отрицания. Сложные отрицания и неоднозначный разговорный текст могут требовать ручного ввода фактов.

Прямой вывод монотонно добавляет истинные заключения. Явно ложные факты он не перезаписывает. Неуказанный факт остаётся неизвестным. NOT от неизвестного также неизвестен. При отсутствии доказательства правило не срабатывает.

Связи и фреймы помогают объяснить сведения о компонентах. Они не измеряют реальное состояние компьютера. Для изменения сети следует отредактировать knowledge/semantic_network.json, затем заново открыть раздел.

## Оценка моделей

600 примеров, восемь бинарных признаков, шесть категорий. Примеры получены из прототипов с вероятностью инверсии признака 8%. Возможны одинаковые симптомы с разными метками. Это ограничение генератора.

Для оценки GroupShuffleSplit с seed=42 держит одинаковые векторы признаков только в одной части данных. Получилось 357 обучающих и 243 тестовых строки. Классы в тесте представлены неравномерно. Accuracy нужно читать вместе с precision, recall, F1 и матрицей ошибок в reports/. Особенно слаба диагностика видео у Random Forest. На реальных данных качество не измерялось.
