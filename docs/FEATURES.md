# Диалоговая диагностика CoreSense

## Уточняющие вопросы

Откройте «ИИ-помощник», введите «Компьютер не включается» и нажмите «Новая диагностика». Справа появится вопрос об индикаторе. Ответы «Да», «Нет» и «Не знаю» обновляют факты и повторно запускают вывод. Неизвестный ответ остаётся неизвестным и не считается отрицанием. Вопросы зависят от симптомов и не повторяются в той же сессии.

Пример для NOT: введите «Нет интернета». На вопрос «Компьютер включается?» ответьте «Да». Это устанавливает computer_not_starting=False и позволяет проверить R4.

Нажатие «Новая диагностика» всегда создаёт отдельную запись. Для продолжения имеющейся используйте вопросы и кнопки шагов справа или откройте её из истории.

## План проверки

Помощник выбирает одну категорию плана по правилам и сообщённым симптомам. Для нескольких одновременных симптомов приоритет имеет перегрев. ML-прогноз сам по себе не выбирает план.

«Проверил — не помогло» переводит к следующей проверке. «Помогло» завершает план по сообщению пользователя. «Пропустить шаг» сохраняет пропуск. Завершённый план без успешного шага предлагает обратиться к специалисту. Программа не выполняет проверки оборудования автоматически.

## История

Раздел «История» ищет записи по тексту исходного запроса. «Открыть и продолжить» восстанавливает факты, ответы на вопросы и результаты шагов. Записи хранятся локально в user_data/history.sqlite3, настройки в user_data/settings.json. Они не включаются в Git и не отправляются в облако.

Для тестов или отдельного профиля можно задать переменную окружения CORESENSE_DATA_DIR. Она меняет папку пользовательских данных, а не базу экспертных знаний.

## Схема ПК

Нажмите на компонент на схеме или выберите его из списка под схемой. Справа отобразятся фрейм со свойствами и исходящие связи из семантической сети. Это учебная схема, а не сканирование оборудования этого компьютера.

## PDF

Нажмите «Сохранить PDF» в помощнике и выберите файл. Можно экспортировать и запись, открытую из истории. Отчёт содержит исходный запрос, факты, результаты анализа и отметки выполнения шагов. ReportLab встраивает системный шрифт Arial или DejaVu Sans для поддержки русского текста. Существующий файл заменяется только после выбора и подтверждения в диалоге сохранения.

## Настройки

Выберите тёмную, светлую или системную тему. При отключении анимаций ответ появляется сразу, пульсация и движение индикатора отключаются. Обе настройки сохраняются между запусками.

## Проверка интерфейса

```powershell
.\.venv\Scripts\python.exe tests/gui_smoke.py
```

Проверка открывает все разделы, проходит анализ, восстанавливает запись из истории, перебирает компоненты и темы. Для неё используется отдельная временная папка данных.
